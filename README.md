## Highlights

- Real-time task and project workflows with authentication, search, filtering, and pagination
- Optimistic UI updates and server-state management with React Query
- Client-side state management with Zustand
- Real-time events through Socket.IO / WebSockets
- Background job processing with BullMQ and Redis
- Asynchronous Web Push notifications

## Built With

**Frontend**  
Next.js · React · TypeScript · React Query · Zustand · Tailwind CSS · shadcn/ui

**Backend & Data**  
Node.js · REST APIs · Prisma · PostgreSQL · Redis · Socket.IO · BullMQ
